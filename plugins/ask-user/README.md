# Ask User

This is the `ask_user` plugin in the [Prime Plugins](https://github.com/am-will/prime-plugins) collection.

It asks a focused multiple-choice question, always adds an `Other (type your own answer)` choice, and collects a freeform answer when that choice is selected.

The root collection is installed with:

```bash
prime-agent package install https://github.com/am-will/prime-plugins
```
